# GestorMed - Frontend

Interfaz web del sistema de gestión de incapacidades médicas.

## Tecnologías
- HTML
- CSS
- JavaScript

## Páginas
- Login (index.html)
- Gestión de empleados
- Gestión de incapacidades
- Seguimiento de incapacidades

## Conexión con el backend
Este frontend consume las APIs del repositorio [GestorMed](https://github.com/migu3l3on22/GestorMed):

- ms-auth → puerto 8001
- ms-empleados → puerto 8002
- ms-incapacidades → puerto 8003
- ms-seguimiento → puerto 8004
